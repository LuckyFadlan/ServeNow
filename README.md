## 📌 Ringkasan Platform

**ServeNow OS** adalah platform *Customer Service Omnichannel & Operational Transformation* berbasis cloud yang dirancang untuk memutus hubungan linear antara penambahan pelanggan dan pembengkakan biaya (menghindari penambahan 223 karyawan untuk melayani 120 pelanggan).

Platform ini menggabungkan dua lapis utama:
1. **Lapis Operasional Layanan (Halaman 2 Dokumen Kasus)**: Ruang kerja agen *Customer 360 Workspace*, integrasi omnichannel (WhatsApp, Telepon, Chat, Email), pemicu SLA otomatis, rekomendasi AI Agent Assist, dan 6 tombol disposisi alur kerja.
2. **Lapis Manajemen & Transformasi (Kerangka S.E.R.V.E & N.O.W)**: Simulator finansial rasio karyawan/pelanggan, matriks batas wewenang (DOA), paket implementasi 8 minggu, lapis kepatuhan AI OJK/UU PDP, serta scorecard kinerja 4 dimensi.

## 🚀 Fitur Unggulan

### 1. 🎧 Customer 360 Agent Workspace (Halaman 2, Box 4 & 5)
- **Single-Screen Workspace**: Profil nasabah terpadu dengan 4 pilar status: **Policy/Plan**, **Billing Status**, **Claim/Dispute**, dan **Open Ticket**.
- **Omnichannel Streaming**: Obrolan dua arah untuk WhatsApp dan Live Chat dengan penyamaran data sensitif (*UU PDP Edge Scrubber*).
- **Voice Call Audio Player**: Pemutar rekaman suara panggilan telepon dengan visualisasi waveform dan transkrip otomatis.
- **AI Agent Assist**: Rekomendasi respons cepat berbasis SOP perbankan OJK (*1-Click Insert*).
- **6 Tombol Disposisi Aksi**:
  1. *Resolved (Solve in 1st Contact / FCR)*
  2. *Create Ticket (Assign Tier 2)*
  3. *Escalate (Supervisor / Dept via DOA Gate)*
  4. *Callback / Follow-up (Jadwal kontak ulang)*
  5. *Refer to Sales (Lead Pipeline)*
  6. *Send Survey (CSAT 1-5 Bintang otomatis)*

### 2. 👔 Supervisor Command Center (Halaman 2, Box 8)
- **Live Agent Status Board**: Pemantauan status agen *real-time* (*Available, On Call, In Chat, Break, After-Call Work*).
- **Waiting Queue Telemetry**: Kedalaman antrean masuk, kecepatan menjawab panggilan (*Average Speed of Answer*), dan rata-rata durasi penanganan (*AHT*).
- **Quality Monitoring (QM) & Coaching Rubric**: Lembar audit rekaman percakapan 4 parameter (*Greeting/KYC, Diagnosa SOP, Akurasi Solusi, Etiket*) dengan formulir *coaching note* langsung ke rekam jejak staf.

### 3. 📊 Executive Cockpit & The Decoupling Simulator
- **Simulator Rasio Karyawan per Pelanggan**:
  - **Status Quo (1,86)**: 120 klien butuh 223 staf $\to$ Gaji Rp42,8 M $\to$ **Rugi -Rp7,3 Miliar**.
  - **Model S.E.R.V.E. (1,15)**: 120 klien hanya butuh 138 staf $\to$ Gaji Rp26,5 M $\to$ **Untung Rp7,86 Miliar (Margin 17,5%, laba naik 20x lipat)**.
- **Roadmap 36 Bulan**: 4 Fase (*Ukur, Standarisasi, Sistematisasi, Skala*) dan 3 titik evaluasi penalti target (*Decision Gates*).

### 4. ⚙️ Delivery & Blueprint Studio (Pilar R - Routinize)
- **3 Paket Implementasi Baku**: *Standard (6 minggu)*, *Advanced (10 minggu)*, dan *Enterprise (14 minggu)*.
- **Linimasa Sprint 8 Minggu**: Memangkas siklus 19 minggu menjadi 8 minggu, menaikkan kapasitas tim **2,4x lipat** (16 $\to$ 39 proyek/tahun) oleh tim yang sama tanpa menambah staf programmer.
- **Katalog Blueprint Industri**: Template siap pakai untuk Retail, Jasa Keuangan (BFSI), Rumah Sakit (BPJS), Pendidikan, dan Gedung Properti.

### 5. 🛡️ Lapis Kepatuhan AI / The Local Moat (Pilar O - Own the Local Moat)
- **Sandbox Penyamaran UU PDP No. 27/2022**: Deteksi dan masking otomatis NIK 16 digit, nomor kartu bank, dan nomor telepon.
- **Standar Tata Kelola AI Perbankan OJK 2025**: Jejak audit digital *immutable* SHA-256, penguncian verifikasi manusia (*mandatory human-in-the-loop*), dan kedaulatan server lokal di Jakarta IDC Tier IV.

### 6. ⚖️ Tata Kelola & Matriks DOA (Pilar S & E)
- Memangkas *Span of Control* dari **26:1 menjadi 8,3:1**.
- Simulator perutean wewenang bernominal: Diskon ($\le 10\%$ Head, $10-20\%$ Direktur, $>20\%$ Dirut) dan OPEX ($\le$ Rp10 jt Head, $\le$ Rp50 jt Direktur, $>$ Rp50 jt Dirut).

### 7. 👥 Scorecard Kinerja Individu (Pilar E - Evaluate)
- Scorecard 4 dimensi berbobot: Target/Output (40%), Kualitas Kerja (30%), Disiplin Jam Inti Core Hours 10.00–16.00 WIB (20%), dan Efisiensi Lembur (10%).
- Audit 7 kategori akar masalah keterlambatan untuk menghentikan pemborosan Rp811 Juta per tahun.

## 💻 Panduan Menjalankan Aplikasi Lokal

### Prasyarat
- Node.js (v18 atau lebih baru)
- npm

### Langkah Instalasi
```bash
# 1. Clone repositori ini
git clone https://github.com/LuckyFadlan/ServeNow.git

# 2. Masuk ke direktori proyek
cd ServeNow

# 3. Install seluruh dependensi
npm install

# 4. Jalankan development server
npm run dev

# Atau jalankan versi produksi yang telah di-build:
npm run build
npm run preview
```

Buka browser Anda di `http://localhost:5173` atau `http://localhost:4173`.
